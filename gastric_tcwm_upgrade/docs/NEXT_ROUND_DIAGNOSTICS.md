# 胃癌下一轮诊断结果：P1 与 P2.1

日期：2026-09-29。本文记录原研究训练代码完成的固定特征诊断和历史
`token_prior` 先验预测评价。G0/G1/G2/G3 训练也已完成，成绩单独见
[本轮训练结果](NEXT_ROUND_RESULTS.md)。

当前证据支持继续定位观察同化和读出的问题，但尚未证明 CT 增量或世界模型有效。固定特征模型加入 CT1 后有初步收益；历史 `token_prior` 在新定义的绝对 CT1 聚合目标空间中，点预测和分布评分均明显落后于训练均值基线。

## 数据与证据边界

沿用已有 521 名原训练患者的三折嵌套划分，外层患者每人只计一次，合计 118 个记录性复发阳性。原 65 人验证集和 65 人测试集保持标签屏蔽，本次没有评分。原外层 OOF 已用于开发选择，本次结果仍是开发研究，不能称为独立确认。

| 外层折 | 内层训练人数 / 阳性 | 内层选择人数 | 外层评价人数 / 阳性 |
| --- | --- | --- | --- |
| 0 | 277 / 63 | 70 | 174 / 39 |
| 1 | 277 / 62 | 70 | 174 / 40 |
| 2 | 278 / 63 | 70 | 173 / 39 |

终点仍是记录性复发二分类，没有转换为一年或两年生存风险。治疗描述和 CT 间隔均按明确的回顾性情景解释，不作因果干预结论；四个治疗 token 仍是描述分组。

历史结果不回写：修复模型原测试 AUROC 0.6240，临床单独 0.6253；历史内部 OOF clinical 0.5892、token_control S1 0.5789、token_prior S1 0.5989。历史 predictive8/32 的绝对 CT1 点预测 R² 为 -0.233 / -0.500。这些是已有模型及已有口径的结果，不能替换为本文的新分数，也不能直接据本文排序声称历史模型提升。

## P1：固定特征诊断

B0 为内层训练患病率；B1 为 clinical32；B2 加入合法声明的治疗情景和查询间隔；B3 再加入 CT0；B4 再加入合法真实 CT1。B4 是不同可用信息时点的诊断对照，不是 S0 部署模型。所有模型使用相同患者资格，一人一个复发目标；这里不使用三阶段权重或 MC 抽样，B0 也不等同于神经训练中的初始化候选。

每折核验已有临床和治疗编码器的拟合患者与内层训练集完全相同。CT0/CT1 共用该折训练影像拟合的 PCA，以扫描的通道均值拟合投影，再对每人的 27 个投影 token 聚合均值和总体标准差。rank 预先固定为 8、32；27 个 token 不作为 27 名独立患者。临床、治疗、间隔和 CT 汇总特征的后续标准化也仅拟合内层训练患者。

分类器是 FP64、full-batch L-BFGS，目标为 `mean(BCE) + lambda/2 * ||w||²`，截距不惩罚。lambda 网格为 `0.001 / 0.01 / 0.1 / 1`，只以内层选择集的未加惩罚 NLL 选取收敛候选，不利用外层分数调参，也没有混用原编码器进行外层训练全集 refit。96 个候选全部收敛，最大 247 次迭代，最终最大绝对梯度不超过 `9.274e-8`，预算上限为 2000 次。

NLL 和 Brier 越低越好，AUROC 和 AP 越高越好。B0/B1/B2 在两个 rank 下完全相同。

| B1 临床 | 不适用 | 0.531403 | 0.173732 | 0.580940 | 0.290843 |

| B4 加 CT1 | 8 | 0.527220 | 0.172366 | 0.592800 | 0.299463 |

## P2.1：历史 token_prior 的先验预测

这里读取历史三折 `token_prior/inference.pt`，没有重新训练或扩大预测器。固定 `K=32`、seed 17、患者 case-key MC，使用 CUDA、batch 8；此 K 是本次历史预测诊断设置，不是后续 G0-G3 已统一锁定的 K64 选模设置。

前向调用固定 `max_stage=0, compute_aux=False`。输入白名单物理移除 CT1、术后观察、标签及 CT1 可用阶段，未来影像有效标志置为 false。对先验注入状态逐样本解码，再进行固定特征聚合；真实 CT1 只在前向结束后用于评分。

### 目标空间与基线的归一化核验

CT 投影沿用 P1 的训练折共享 PCA。预测评分再用同一折合法配对训练 CT1 的聚合均值和总体标准差进行归一化，标准差下限为 0.05，目标维数为 `2 * rank`。训练均值、复制 CT0、线性预测、先验单样本和先验 MC 均值全部进入这同一个冻结目标空间，复制 CT0 不使用自身单独拟合的评分尺度。

正则化线性比较器使用训练折标准化的 CT0 与临床/情景条件，按每个目标通道的平均平方误差加 `0.1 * ||w||²` 拟合，截距不惩罚。lambda 0.1 是预先固定的参考设置，未用外层结果搜索；因此其负结果不表示已经排除所有线性预测器。Gaussian 分布比较器使用训练 CT1 聚合目标的完整总体协方差，加 `1e-6 * I`，同样不拟合外层统计。

私有每折报告保存完整拟合患者来源；公开报告保留 `target_space_id`、`projection_space_id`、拟合人数、目标统计 hash 和归一化说明，不公开患者清单或直接由患者成员生成的 hash。P2.1 的 `target_space_id` 还包含 CT1 目标标准化，因此与 P1 的投影 ID 不等同。不同 rank、不同外层折及历史 predictive8/32 使用不同目标坐标；不得用它们的原始 MSE 大小作跨空间优劣判断。

`skill = 1 - sum(模型平方误差) / sum(训练 CT1 均值平方误差)`。合并时先跨折相加平方误差，再计算比值；不是逐折 R² 的算术平均。负值表示低于对应训练均值参考。

| 训练 CT1 均值 | 0.993794 / 0 | 0.972442 / 0 |
| 复制 CT0 | 1.516904 / -0.526377 | 1.651035 / -0.697824 |
| CT0 + 条件线性预测 | 1.036488 / -0.042961 | 1.180040 / -0.213481 |

### 分布与集合评分

| rank / 分布 | Energy score，越低越好 | 边际 90% 覆盖率 | 平均投影方差 |
| --- | --- | --- | --- |
| 8 / 先验 | 5.139930 | 0.180% | 4.540e-6 |
| 8 / 训练 Gaussian | 2.738380 | 85.593% | 0.998743 |
| 32 / 先验 | 10.500443 | 0.117% | 2.474e-6 |
| 32 / 训练 Gaussian | 5.479445 | 85.994% | 1.003399 |

Energy score 在各自冻结目标空间内计算，样本两两距离项使用 `K*(K-1)` 分母。这些覆盖率是特征坐标的边际覆盖，不是患者临床置信区间；32 个潜变量样本也不是 32 名患者。先验解码后的聚合分布非常窄，而且其中心预测存在明显误差，不能仅归因于 MC 样本不足。该观察不证明原始 CT 缺少信息，也不识别方差缩小的唯一机制。

另用历史 checkpoint 中仅由训练 CT0 拟合的通道尺度，计算原有 token 置换不变集合损失及原通道聚合误差，不做跨时点同位 token MSE。先验单样本集合损失 0.665922，逐样本集合损失的 MC 平均 0.665911，复制 CT0 为 0.756655。训练通道均值重复为 27 个相同 token 的退化集合参考为 0.816402；它不等同于上表中保留 CT1 聚合标准差信息的训练均值基线，不能因先验胜过这一退化集合就宣称总体预测有效。

先验 MC 聚合后的原通道均值 MSE 为 0.180174、标准差 MSE 为 0.110815，使用上述训练 CT0 通道尺度。这些数值与 PCA 目标 MSE 属于不同评分口径。集合损失改善与绝对投影预测失败同时出现，说明需要分别检查预测中心、随机分布和集合目标，不能用单个训练损失替代未来预测验证。本轮未据此启用 P2.2 的新预测损失、P2.4 的 pCR@CT1、较大 Flow 或新 CT 骨干。
