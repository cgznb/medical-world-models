# 2026-09-29 原训练代码优化与真实训练结果

本轮修改与真实训练首先在原研究代码和原 Python 环境中完成，随后将相同
运行源码、配置、测试和聚合结果同步至此公开目录。患者数据、权重及恢复
检查点保留在私有环境，历史数值结果没有回写。

## 结论

工程验收和预先规定的 G0-G3 三折训练均已完成。176 项测试通过，12 次
真实训练全部正常结束，共 5400 个监督更新。阶段权重、临床零步候选、
病例级 MC、分支诊断、观测辅助梯度及导出/恢复合同已得到验证。

本轮没有证明可靠的新增预后收益。G0 的 S1 AUROC 为 0.5964，临床 anchor
为 0.5892，差值 0.00711 的固定 OOF 配对 bootstrap 95% 区间为
[-0.00255, 0.01661]。G1 降低世界模型学习率、G2 增加观察重建、G3 简化
读出，都没有稳定超过参考臂。因此保留旧研究用检查点，不用本轮 OOF
挑选“最好 seed”，不依据原验证集重新选择全量训练预算。

新增独立 seed 29/43 训练没有触发：G1/G3 的逐折概率误差方向不一致；
G2 虽有较小的 NLL 改善，但 AUROC 在两折下降，第三折加权 NLL 的差值
仅约 1.5e-6，低于 MC 波动和 min_delta。没有足够稳定的综合方向支持
本轮自动扩大训练矩阵。此判断不把置信区间跨零解释为“肯定没有信息”。

## 统一评价

终点是记录性复发二分类。沿用原训练集 521 人，其中 118 人阳性；原
65 人验证集及 65 人测试集没有重新评分。内层训练 277/277/278 人，
阳性 63/62/63；内层选模各 70 人；外层分别 174/174/173 人。
外层 OOF 已经有开发接触，以下均为开发结果，不是新增独立验证。

所有模型使用 seed17；训练 MC K4；选模及最终评价统一 K64、病例级固定
随机数和 antithetic 配对。阶段权重为 (0.5,0.5,0)，S2 仍保留并与 S1
相同。选模 MC seed10017，统一最终评价 seed17，均事先固定。

区间来自同患者固定 OOF 的 2000 次按结局分层配对 bootstrap，seed20260929；
不包含重新训练和候选选择的全部不确定性。

这些单项改动没有表现为一致的区分度与概率质量改善。G3 参数量由

历史 token_prior 的 0.5989 使用不同阶段权重、MC 和训练日程，不能把
它与本轮分数之差简单归因到某一个修改；历史数字保持不变。

## 诊断与验收

- 176 项测试通过，包括旧 checkpoint 严格加载、阶段权重不改变资格、
  MC batch1/8/16 与重排序、inactive optimizer、CT1 辅助梯度、泄漏边界、
  baseline0、旧合同兼容和精确恢复。CUDA 短探针的独立推理概率误差 <6e-8。
- 12 个选中模型均核验导出权重等于 best.pt；clinical anchor 与预处理
  buffers 在初始化、best、last 之间保持相同。12 组依赖探针的四类边界
  检查全部精确为零。依赖探针使用内层验证集，不另做外层选择。
- G2 观察重建确实给 observation_attention/gate/decoder 非零梯度。
  这证明通路有效，不证明结局收益。CT1 置换使 NLL 变差的折数为
  G0 1/3、G1 1/3、G2 2/3、G3 1/3，方向仍不稳定。
- K32 的 MC NLL SD 接近 min_delta，因此统一改 K64；K64 的 SD 仍约
  7.63e-5，不能把很小的差异当成充分收敛的确定收益。
- 固定特征 B4 的 CT1 信号及历史 token_prior 的负预测 skill 见
  [诊断报告](NEXT_ROUND_DIAGNOSTICS.md)。二者共同提示需要继续区分
  输入表征中的可用信号、未来预测、观察同化和结局读出的问题。
