# TC-BWM：治疗情景条件化的信念状态世界模型
## 基于 Generated651 的算法审阅、研究方案与可运行升级实现

交付日期：2026-09-28。审阅基线：`cgznb/gastric-multistage-generated651`，提交 `aec8cbe08157687fd447594c8a9406d6ee5a464d`。实现版本：0.1.0。

本报告严格区分三件事：已经实现并测试的功能、需要真实数据验证的研究假设、当前数据不能支持的医学结论。代码包完整覆盖新增训练、推理、数据转换、损失、评估与测试路径，但不是原仓库所有历史实验文件的镜像。它可以独立运行，也可以非破坏性地安装进原仓库；原版静态模型保留为对照。公开版本包含后续私有真实队列实验的聚合结果，不包含患者数据或临床训练权重。

下文主要描述原始默认算法。后续加入的临床锚定、CT1直接更新、prior直接CT监督、低维预测CT架构及固定预算选点，分别见 [修复说明](LOCAL_REPAIR.md) 和 [CT开发说明](CT_OPTIMIZATION.md)。这些实验尚未证明CT世界模型相对临床基线的可靠增益。

## 1. 最重要的修正：预测的是哪一种风险？

用户指出“后续治疗会影响复发”，这一点必须进入任务定义，不能仅在讨论部分提醒。设历史信息为 H_k，后续明确指定的治疗情景为 a，终点为 Y_u。当前实现估计的对象是治疗情景条件下的关联预测：

\[
R_k(u;a)=P_{\mathrm{obs}}(Y_u=1\mid H_k,\text{treatment context}=a).
\]

它不是已经识别的干预分布 P(Y_u^{do(a)}=1|H_k)，也不是“不继续治疗的固有危险程度”。当 a 来自回顾性完整治疗汇总，早期输出必须解释为“在给定这条实际治疗路径条件下的回顾性预测”，不能称为真实部署时已经掌握未来治疗的前瞻性预测。即使换成手工输入的假设方案，网络也不会因此自动成为因果估计器。条件关联与干预预测之间还需要一致性、序贯可交换性、治疗重叠、完整时间变化混杂等识别条件；架构无法代替这些条件。[R6]

最终观察到 Y=0，只能监督与该患者事实治疗情景匹配的训练样本。代码没有把治疗 A 下的 Y=0 复制给治疗 B，也没有从所有患者均手术的数据学习“手术相对不手术的获益”。未观察到的治疗组合在推理时默认拒绝，只有显式的研究性越界开关能输出带警告的模型外推。

一个最终结局可以对应多个事实情景下的历史前缀，原因是各前缀使用不同的信息估计同一个结局分布，而不是要求各阶段状态、危险程度、概率都相等。每个患者的前缀损失先平均，患者仍然只占一个统计单位。

### 1.1 本版不声称实现了任意动态治疗策略

原数据只提供新辅助治疗的区间摘要和手术状态，缺少逐疗程剂量、方案调整时间和术后治疗轨迹。本版使用“明确给定的区间治疗情景＋手术参考转移”，不把它包装成可处理任意自适应策略 π(H_t) 的完整序贯因果世界模型。需要优化治疗策略时，应先建立有时间戳的动作及混杂数据合同，再设计 g-computation / 权重或双稳健估计，而不是直接对本版输出做 argmin。

## 2. 代码审阅发现：必须保留和必须改变的部分

### 2.1 原网络的真实含义

`generated700_models.py::FutureWorld` 使用冻结 CT 特征 [B,27,768]，投影至 [B,27,128]，加入 3×3×3 网格位置编码。临床32维、4×82维治疗描述和1维间隔编码构成361维输入，并转为6个条件token。四层 SpatialTransition 混合四头 Transformer、两种空洞尺度的 depthwise 3D convolution、FiLM 和残差点卷积。S1 是生成的治疗后潜在状态，真实 CT1 只作为训练目标。

`surgery_s2_models.py` 再用临床和手术状态驱动四层残差转移，得到 S2。只有 present 状态激活转移。最终残差零初始化。S2 没有真实术后 CT 或病理重建监督；因此它是面向预后的手术情景潜在表示，而不是已被验证的真实术后微转移状态。[B1–B3]

原 pCR 和复发输出是训练折内拟合的固定 logistic anchor，加上神经残差。复发头读取基线、生成S2以及完整条件，并非单独 `head(S2)`。原 anchor 接受完整治疗摘要和间隔，不能直接当作所有早期阶段均合法的输入通道。[B2–B3]

### 2.2 四个治疗 token 不是四个治疗时间点

这是本次最重要的数据审计结果。`data/treatment_compact.py` 把39个治疗描述分到4个类别组，每组82维：39个取值槽、39个已知性槽、4个组标识槽。它不是四个时间步，也不是四个治疗周期。源码明确标记：

`time_basis = retrospective_interval_summary_not_baseline_known_fact`

所以不得将四组编码当作 A0、A1、A2、A3，进而构造虚假的多次剂量转移。本版原样复用其编码合同和训练折词汇支持，保留6个条件token结构。[B4]

### 2.3 CT0/CT1 不具备逐 token 解剖对应

原代码明确采用特征集合损失，而不是逐体素或逐token配准监督。新版本继续使用排序随机投影的集合距离，不强迫第j个CT0区域与第j个CT1区域相等。共享编码权重意味着相同特征变换，不意味着治疗前后图像应该一致。27个网格token的局部卷积保留原版单次观测内部的空间处理；跨时间匹配仍是集合层面的，不声称获得了真实解剖运动场。[B2]

### 2.4 数据决定了当前能回答什么

原选定管线读取“复发转移状态”的二分类标签，而没有使用复发日期、删失日期和各预测时点的信息可用日期。原表格可能包含这些数据，但不能假定现成缓存已经包含。

当前全651队列已接受手术并具有完整配对CT。术前预测的目标人群因此也是这个经过选择的手术/配对影像人群。不能不经验证推广至所有新辅助治疗患者，更不能把后续未完成手术者的风险用此队列结果直接代表。样本选择、失访与随访长短不是增加Transformer层数可以解决的问题。[B1,B5]

## 3. 核心方案：不让 S0/S1/S2 相等，而让它们通向统一参考状态

建议名称为 **Treatment-Contextualized Belief World Model，TC-BWM**。名称只是该实现的研究标签，不代表已确立的新方法或已达成SOTA。

原思路“同维度状态→直接共享末端头”存在分布错位。本版改成：**不同信息前缀形成不同信念分布，在同一治疗情景下映射到统一参考状态，再由同一个结局头读取。**

```text
CT0 + 基线临床 + 明确治疗/间隔情景
        │
        ├─ 共享CT投影 + 原4层空间转移 → h1−
        │                                     │
        │                                p(z1 | H0,a)
        │                                     │
        │                              多个可能的S1样本
        │                                     │
        │                          同一手术参考转移 → S*样本
        │                                     │
        │                               共享结局头 → S0风险
        │
真实CT1在S1可用 → 共享CT编码 → 观测后验 q(z1 | H1,a)
                                              │
                                   同一手术参考转移 → S*样本
                                              │
                                        共享结局头 → S1风险

真实术后特征在S2可用 → 术后观测更新 → 更新的S*样本
                                              │
                                        共享结局头 → S2风险
```

基线CT记忆和治疗条件也送入共享头，避免把没有证明充分性的单个晚期向量当作完整预后统计量。公式是：

\[
\widehat R_k(u;a)=\frac1M\sum_{m=1}^{M}G_\psi\big(E(X_0),S_{*,k}^{(m)},C(a),u,\ell_k\big).
\]

其中 k 是信息前缀，a 是固定的情景，ℓ_k 是风险集进入时点。S* 是共同参考表示，不是假定存在的真实CT2。只有确实提供了术后观察，才有术后更新项。

### 3.1 为什么当前数据上 S1 和 S2 可以相等？

假设S1已经有真实CT1，同时指定“随后进行手术”；S2只是同一手术情景的网络内部表示，没有任何新病理、手术质量或其他状态证据，进入时点也相同。此时 S1 和 S2 的风险可以完全一样。代码在 eval、固定随机种子且条件不变时特意保留这一性质，并有精确相等测试。

这不是少写了一个预测头，而是不制造信息。只有获得新观测、改变已知治疗情景，或改变合法的事件未发生条件和时间目标时，才有充分理由更新风险。当前二分类缓存不能凭空制造三个有不同临床证据的预测时点。

真实pCR、病理分期、切缘或病理图像若在S2已可用，可作为新增术后观测。但需要明确可用时间并重新构建数据；不能自动把原labels里的pCR塞入所有阶段。当前默认 `postoperative_dim=0`，不偷读这些标签。

## 4. 网络模块与张量维度

### 4.1 共享CT编码与确定性空间转移

输入 CT0/CT1 为 [B,27,D]，D默认768。共享 Linear(D,128)+LayerNorm 与网格位置投影得到 [B,27,128]。CT0的标准化均值和尺度仅在训练患者上拟合，CT1使用同一变换。基础Swin编码器保持冻结缓存形式，本次没有训练新的CT基础模型。

原四层 `SpatialTransition` 保留，每层包括 `TransformerEncoderLayer(128,4,512)`、3×3×3 depthwise卷积、dilation=2的depthwise卷积、GroupNorm和FiLM。确定性预测状态 h1− 为 [B,27,128]。它是基线和明确治疗情景的函数；真实CT1不会进入这条早期预测路径。

### 4.2 信念状态：Gaussian 基线

对预测状态做四个seed的集合池化，生成32维均值和对数方差：

\[
p_\theta(z_1|H_0,a)=\mathcal N(\mu_p,\operatorname{diag}(\exp l_p)).
\]

观测更新使用两层 pre-norm Cross-Attention，Query来自h1−，Key/Value来自真实CT1编码，经过集合读取生成 qφ(z1|H1,a) 的均值和对数方差。为数值稳定，logvar限制在[-6,2]。输出不是“CT1真值风险”，而是根据真实检查更新的潜在信念。

采样得到 [B,M,32]，经可训练FiLM注入 [B,M,27,128]。统一手术转移对每个样本工作，之后共享同一预后读取器。常用训练M=4、评估M=16、导出查询M=32。用相同随机数比较前缀，可减少纯采样导致的无意义风险波动。

设计借鉴 DreamerV3 的 observe/imagine 分离、平衡KL和free-nats，但不是复刻DreamerV3：原始开源RSSM使用离散潜变量和GRU式核心；这里使用高斯潜变量、影像空间转移与独立结局似然，没有actor、critic、奖励优化和强化学习循环。[R2]

### 4.3 观测缺失与信息可用性

`image_valid` 区分真实存在的观测和零占位；`ct1_available_stage`取1/2/3，分别表示S1可用、S2才可用、全程不可用。S0预测不读取CT1。缺失时使用先验而非伪造后验。训练有观察丢弃增强，但CT1仍可作为训练目标：目标监督可访问未来观测，不等于推理前向读取未来观测。

术后更新使用两层Cross-Attention及零初始化的残差输出层；只有至少一个有效术后token的患者进入注意力，避免全mask导致NaN。此更新只能在S2使用，pCR分支不能读取它。

### 4.4 共享预后读取器

基线记忆与统一参考状态经过两层双向交叉注意力，然后将二者、变化特征和合法条件拼接，使用8个可学习seed、两层交叉注意力聚合为 [B×M,8,128]。这是 Set Transformer PMA 风格的读取，不给每个seed未经监督地命名“微转移”“免疫状态”。共享的是统计接口，而不是三个时点数值相等。[R1,R3]

二分类版本使用一个共享query输出logit；生存版本用时间区间中点、区间宽度和进入时点生成时间query，两层query-to-state注意力后输出每个时间区间的非负原因别风险率。所有阶段使用同一组网络参数。

### 4.5 可选进阶：条件潜变量 Flow Matching

`prior="flow"` 将Gaussian先验采样替换为条件流采样。32维潜变量拆为4个latent token；四层自注意力、交叉注意力和adaLN-Zero条件块组成速度场。输入包含流时间、当前预测状态h1−和已指定的治疗情景所形成的条件，不包含真实CT1。网络采用DiT的自适应归一化思路，但不是完整DiT图像模型。[R4,R5]

对停止梯度的观测后验样本z+与Gaussian噪声ε构造：

\[
z_\tau=(1-\tau)\epsilon+\tau z^+,
\quad v^*=z^+-\epsilon,
\quad\mathcal L_{FM}=\|v_\theta(z_\tau,\tau,h_1^-)-v^*\|^2.
\]

采样使用可微Heun积分，默认训练4步、评估24步。流时间τ∈[0,1]是生成过程的人工时间，不是患者的临床随访时间；Δt是CT检查间隔，两者不能混为一谈。

**实现边界：** Flow版本仍保留高斯先验/后验KL作为辅助正则，FM拟合观测后验样本。它没有计算KL(q||p_flow)，没有exact-flow对数密度，也不是严格的flow-VAE ELBO；没有EMA教师、目标分布冻结或多层JEPA训练。必须将此版本视为实验先验，和Gaussian版本比较训练稳定性、采样步长敏感性、后验坍塌和真实预后收益。生成分布更加灵活不意味着在651个患者上必然更好。

## 5. 训练目标：结局稀疏，但事实路径可以训练多个合法前缀

### 5.1 终点损失的统计单位

令患者i有合法前缀集合K_i。相同患者的所有前缀使用相同事实治疗情景a_i。代码将每个前缀的混合结局似然取负对数，再对患者的前缀平均：

\[
\mathcal L_{end}=\frac1N\sum_i\frac1{|K_i|}\sum_{k\in K_i}
-\log\left[\frac1M\sum_m p_\psi(y_i|S_{*,ik}^{(m)},H_{ik},a_i)\right].
\]

不能在所有假设治疗a上复用y_i。也不能让有三个检查的患者权重自动变为只有一个检查患者的三倍。数据划分在患者级完成，不在阶段样本级完成。

对于二分类，先算各样本Bernoulli似然再做log-mean-exp；它等价于对平均预测概率的正确二分类似然，而不是把每条随机未来都强制优化到相同标签。实现没有采用原版类别加权BCE，避免把排序倾斜后的sigmoid直接当作绝对概率；但这也不意味着模型已经校准。

### 5.2 观测集合重建

CT目标由观测后验潜变量重建，包含全局均值SmoothL1+cosine、64个固定方向上的排序投影平方距离、token标准差SmoothL1。权重分别1、0.25、0.1；使用训练折图像尺度稳定不同特征量纲。这是原版特征集合目标的延续，而不是像素级生成。该集合距离不是严格概率密度，因此总体目标也不应被称为精确ELBO。

### 5.3 平衡KL及防止退化

\[
\mathcal L_{KL}=\alpha KL(sg(q)\|p)+(1-\alpha)KL(q\|sg(p)).
\]

默认α=0.8，free-nats=0.5，并在预热期间逐步升高KL权重。free-nats给小KL一定容忍度，不强迫所有维度马上贴合先验。需要监测latent概率标准差、后验/先验偏差和FM速度场梯度；不能仅凭加入随机采样就声称刻画了真实患者不确定性。[R2]

### 5.4 pCR辅助任务

pCR从CT0及生成S1读取，训练时不读取真实pCR作为输入，也不读取手术状态、真实CT1或术后观测。这条分支是治疗前情景下的pCR预测辅助任务，与复发终点独立。真实CT1监督通过世界模型损失间接影响参数，不构成pCR推理输入。相应前向信息隔离有单元测试。

### 5.5 总损失和两阶段优化

\[
\mathcal L=\mathcal L_{end}+0.2\mathcal L_{pCR}
+0.1\mathcal L_{CT}+0.02\mathcal L_{KL}
+\mathbb1_{flow}\mathcal L_{FM}.
\]

前15个epoch默认为表征/先验预热，只优化CT、KL和可选FM；之后联合优化全部任务。Flow预热时风险分支使用Gaussian，结束后切换flow先验；这个切换是需要消融的工程选择，并无已验证性能保证。训练从随机初始化开始；也可以导入原空间块，但必须核验原checkpoint训练患者集合与当前训练折完全一致，不能导入使用了当前测试患者训练的“预训练权重”。

默认H128、lr2e-4、AdamW、weight_decay0.01、batch8、梯度裁剪1、patience25、最长150epoch。GPU可启用BF16；CPU默认关闭。所有数值都是起始配置，不是对真实数据调出的最优超参数。Gaussian首先作为稳定主线，Flow作为单独实验，不建议未经消融直接用最复杂版本代替所有对照。

## 6. 生存和竞争事件：一年、两年不是两个随意的sigmoid

### 6.1 数据要求与时间原点

生存版本要求明确提供 time、event、entry 三组张量，单位统一为月且有明确time_origin。time是首次复发/竞争死亡/末次确认未发生事件随访三者对应的观察时间，event为0删失、1复发、2无复发竞争死亡；entry为每个前缀的风险集进入时点。没有这些数据会拒绝生存训练。

选择“术后复发”为终点时，术前S0/S1的预测是对该手术队列术后过程的预测，entry=0表示终点尚未开始计时，不是伪造术前日期为手术日期。术后第6个月再次预测则entry=6，且只对当时仍未发生终点者有效。若事件已发生，不再预测首次复发；要研究再次复发应另建多状态/复发事件模型，本版没有实现。

当前sidecar使用已经核验并转换的月数与合法性标记，不替用户判断模糊病历日期或自动推断病理报告什么时候可用。如果仅知道复发在两次检查之间发生，属于区间删失；本版按精确事件时间/右删失建模，不能直接把某个随意中点当真值。

### 6.2 风险率、密度和似然

默认时间分段为0、3、6、12、18、24、36、48、60个月。对每个状态样本输出λ_{j,c}=softplus(a_{j,c})+ε。

从已知entry=ℓ到观察时间t的累计全因风险为：

\[
A(t;\ell)=\sum_j\left(\sum_c\lambda_{j,c}\right)d_j(\ell,t),
\quad S(t|\ell)=e^{-A(t;\ell)}.
\]

发生原因c事件时似然为S(t|ℓ)λ_c(t)，删失时为S(t|ℓ)。多个潜变量样本在似然层平均后取log。内部区间边界使用右侧风险率，最后端点包含在最后一区间。超过模型最大时间不静默外推；可显式延长bins，或在数据转换中明确行政删失，而不是悄悄截断。[R7]

### 6.3 复发累积发生率

有竞争死亡时，复发风险是：

\[
F_{rec}(u|\ell)=\int_\ell^u S(t|\ell)\lambda_{rec}(t)dt,
\]

而不是1减全因生存。每个时间区间内可解析积分，代码精确处理部分区间暴露。单个样本和混合输出都满足：S+F_rec+F_death=1。相同前缀下F_rec(12)≤F_rec(24)，但S0和S1对同一个24个月终点的预测可升可降。

输出12、24个月的是术后相应绝对终点时间的条件风险；希望预测“从现在开始未来12个月”时，应查询entry+12，而不是重新把时钟归零。不能把不同目标窗口的前缀概率强行对齐。

### 6.4 不确定性解释

预测返回潜变量样本间概率标准差和Monte Carlo标准误，后者衡量有限采样的数值误差，不是临床置信区间。另提供多个独立模型的ensemble读取函数，但模型间标准差也未经覆盖率校准。没有实现conformal survival区间或因果效应区间，不声称这些已经具备。

## 7. 跨阶段一致性：这次实现了什么，没有实现什么？

共享参考转移、共享头、共同随机数、严格观测可用性，使风险更新来自信念更新而非新增三个任意分类器。没有加入||S0-S1||²、||S1-S2||²，亦没有把不同治疗策略的风险拉到相等。

前面讨论的条件期望恒等式 R_k=E[R_{k+1}|H_k]，要求相同目标、相同政策/治疗语义和正确的条件观测生成过程。本版没有足够的术后观测分布和明确动态政策，因此**没有硬加一个号称严格成立的Bellman/鞅一致性损失**。独立训练的观测后验与先验也不保证精确满足该恒等式。代码实现的是结构上的参考状态共用，而非数学上已经证明的跨阶段校准。

作为后续研究，可以在真实纵向观测充分时，显式采样下一观测、重新做后验更新、在同一治疗规则下比较风险边缘分布。该扩展必须与普通蒸馏、多前缀监督及概率校准作对照，不能单靠恒等式本身声称算法创新。

## 8. 与公开代码的关系：复用、重实现和不采用

已逐段核对8个外部公开仓库的具体模块，另核对近期论文；不是仅列出论文名字，也不是声称完整复现8套模型。逐文件blob指纹、查看范围和具体取舍见 `SOURCE_AUDIT.md` / `source_audit.json`。

CLARITY（作者页面标注ECCV2026，2026-09-19修订）提供治疗条件潜空间推演与预后读取，是最直接相关工作。双向注意力通过原代码继承，MIT声明保留。它已经把治疗推演与结局联系起来，所以“生成S1再用一个头读风险”本身不能作为本项目主要新意。[R1]

DreamerV3提供先验/后验与平衡KL的训练结构；Set Transformer提供学习query聚合集合；DiT提供adaLN-Zero；Meta Flow Matching提供仿射概率路径和速度监督；pycox提供分段风险的似然实现参考。当前版本将这些机制改成27个CT token、32维随机状态和带删失的终点任务，不加载视频或像素生成大模型。[R2–R5,R7]

Causal Transformer的过去治疗、状态、结局分流及前缀掩码有助于梳理信息边界，但不将其对抗平衡损失照搬成“已消除混杂”的证明。MeWM的TransMIL/Nyström聚合代码显示了医学生成后读取结局的可行架构，但其2D padding/硬编码CUDA习惯和像素生成路径不适合当前3×3×3冻结CT缓存，因此未复制整个架构。[R6,R8]

V-JEPA2.1和LeWorldModel等2026预印本也用于评估稠密表征和稳定自监督方向，但本次没有接入其代码或权重，不把它们计入实际代码复用清单。当前缺少原始CT多尺度训练与外部测试，因此不以视频大模型的名称替代医学表征验证。[R9,R10]

## 10. 运行与数据迁移

完整命令见根目录README。独立合成闭环无需原仓库，只需PyTorch、NumPy、scikit-learn和pytest。真实legacy转换需要原仓库的临床/治疗编码器；先指定患者划分，后拟合训练折词汇与标准化，不得复用由全队列拟合的变换。

二分类原缓存可立即构建新的研究训练路径，但只得到记录状态预测。转换会强制确认回顾性治疗语义，并在元数据中注明“未核验日期的回顾性信息子集”。生存功能通过CSV sidecar显式开启。术后模态需自行加入已授权真实特征及有效性mask，其语义和可用时点由数据管理者核验。

训练默认不评价test；锁定inference.pt后使用单独evaluate命令。重新运行同一目录必须--resume且数据文件SHA、划分、配置完全一致。更换seed或超参数应新建目录。warmstart只复制尺寸匹配的原空间块，不导入旧anchor、旧终点头或不同训练折的归一化。

公开副本的自动化测试聚合记录见 [test_summary.json](../../results/gastric/test_summary.json)。核心验证包括：S0对未来CT1/术后特征不变、S1对真实CT1有响应、pCR不读手术/真实CT1、缺失观测回退、无新信息时S1/S2相等、治疗情景改变影响预测、患者划分隔离、训练折归一化、竞争风险概率守恒、解析删失似然、Gaussian/Flow端到端、checkpoint恢复精确重放、预测接口拒绝标签和非法时间窗。新增测试还覆盖prior直接监督、嵌套折隔离、预测CT架构及固定预算选点。原始JUnit日志和旧合成输出目录不公开。

## 12. 面向论文的实验设计

最小可发表论证不能是“加了Flow，分数略升”。首先要验证在**相同可用信息**下，统一参考表示、观测更新和概率边缘化是否各有贡献。

建议对照包括：原G2静态模型；S0/S1/S2各自的临床+影像直接分类/生存模型；共享头但无世界转移；确定性参考状态转移；Gaussian信念版本；加入真实CT1更新；Flow先验版本；有真实术后模态时加入S2更新。每个阶段的直接预测基线必须获得同样的真实CT1或病理，否则提升可能仅来自更多输入。

生存对照优先考虑Cox/离散风险、PC-Hazard、Dynamic-DeepHit、controlled latent states等；pCR只作为辅助，不用测试集选pCR权重。当前代码实现评估的是逐阶段NLL、AUROC/AP/Brier、IPCW时间窗AUC/Brier和分组校准诊断，未完整实现所有文献基线、C-index、IBS或因果估计。论文完整对照需另行运行，不能把研究计划写成已完成实验。

要特别报告事件数、每个时间窗在险人数、删失支持、治疗组合频数、缺失模态比例、不同阶段的真实信息新增量。对于全员手术的队列，不报告手术与不手术的因果效应。对罕见药物组合不给未经验证的疗效排名。

内部队列已多次用于开发，锁定新方案后应进行患者级嵌套验证、时间外测试或独立中心验证。20个随机seed的测试患者有重叠，不能被当作20个独立临床队列。差异置信区间按患者配对bootstrap，不能把同一患者的三个前缀作为独立样本放大显著性。[B1]

### 12.1 视觉创新的证据还不够时，应怎样加强？

当前保留的是冻结Swin特征缓存，无法仅靠集合距离证明细粒度肿瘤形态变化被正确建模。面向CVPR，值得扩展的是原始CT上的多尺度肿瘤/瘤周/淋巴结表征、可靠的时序配准或显式无对应集合建模，以及跨中心治疗反应任务。空间改进必须与预后获益相连接；只在一个651例内部队列上堆更大Transformer不构成充分视觉贡献。

可以主张和检验的研究方向是“有限终点监督下，治疗情景条件化的概率参考状态与证据更新”。其中共享头、RSSM、Flow Matching、PMA和分段风险均不是新的基本部件。最终的新颖性需要通过机制差异、相关工作对照和实验来确立，不能预先保证CVPR接收或SOTA。

## 13. 决策建议

先运行Gaussian二分类版本，确认合法信息、数据转换和原静态模型的公平对照；有随访数据后切换到生存版本；Gaussian稳定后再比较Flow；只有真实术后信息和可用时间得到核验，才开启术后观测模块。最优先的科学收益来自正确的目标定义、真实观测更新和删失处理，而不是在缺乏时间监督时让网络强行输出12个月与24个月两个数字。

本版的关键结论是：**患者状态、已知治疗情景和未来结局读取要分开；不同阶段靠真实证据更新信念，用同一参考状态/结局接口保持语义一致。最终标签监督事实路径，不替代未观察到的治疗反事实。**
