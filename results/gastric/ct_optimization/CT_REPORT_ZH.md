# 胃癌 CT 世界模型优化与训练报告

日期：2026-09-28。代码：[gastric_tcwm_upgrade](../../../gastric_tcwm_upgrade)。

本轮完成网络修改、6 个配置各 3 折的 18 次嵌套交叉验证训练，以及一次原训练集 521 人的全量重训。补充直接预测监督后，内部复发预测有所改善，但尚未获得稳定的 CT 增益。新候选全量重训后的原验证集 S1 AUROC 为 0.5196，低于上一版约 0.6232，因此不替换上一版研究用模型。

当前保留模型的配置：
[repair_anchored.json](../../../gastric_tcwm_upgrade/configs/repair_anchored.json)。
本轮实验模型仅供复现和诊断。所有训练权重、患者数据及运行合同保留在私有研究环境。

## 1. 找到的问题及实际修改

### 预测分支缺少直接的未来 CT 监督

旧 CT 重建损失监督的是已经读取 CT1 的 posterior 重建，不能单凭该重建损失下降就证明从 CT0 预测未来 CT1 成功。训练患者的梯度探针显示，单独使用这项重建损失时，23 个 prior pool/parameter 张量的梯度为 `None`。prior 原本仍有 KL 和结局损失的间接监督，因此这不是“整个 prior 从未训练”的证据。

已增加 `prior_ct_weight`：用 CT0 生成的 prior 状态直接解码未来 CT 特征，并以真实 CT1 为训练目标。CT1 仅作为目标，不进入 S0 的预测输入。沿用集合重建目标，避免假定独立裁剪的 CT0/CT1 token 存在空间配准。`token_control` 与 `token_prior` 只差这项直接监督，后者权重为 0.1。

### 风险读出削弱了观察更新

原结构的 CT1 更新经过融合、池化和注意力读出后明显缩小；上一版临床锚定模型的神经残差贡献也很小。不能把这一现象单独归罪于 LayerNorm。

已新增 `predictive_ct` 架构：在每折训练患者内拟合并冻结 CT 投影，汇总 token 的均值和标准差，使用小型条件 Gaussian 网络预测绝对 CT1 状态，再以共享线性结局读出接收预测状态或合法的真实 CT1 更新。它保留可学习的手术参考状态变换，因此完整网络仍是非凸模型。增加独立读出学习率和 L2 正则。另实现 `predictive_transition=false` 的直接 CT 对照。

rank 8/32 的预测网络分别有 17,138/30,530 个参数；直接 CT 对照分别为 338/4,418 个参数。原 token 对照和新增 prior 监督模型均为 902,210 个参数。新增预测模型生成的是 CT 潜在状态，不是原始 CT 图像。

### 现有影像表示较粗，未来状态预测仍不可靠

训练集 1,042 张扫描中，439 张（42.1%）采用 stomach fallback；其余采用胃相关肿瘤候选区域。裁剪视野约 192–321 mm，冻结 SwinUNETR 最深层表示只有 `3×3×3` 个空间位置、768 通道。它是包含周围组织的粗 ROI，不能视为专家核验后的纯肿瘤特征。CT0/CT1 独立裁剪，缓存不具备已验证的 token 对应关系。

这些事实支持检查 ROI 和多尺度特征，但不能证明它们是效果差的唯一原因。增加网络深度也不能恢复缓存中已经丢失的局部细节。

本轮复用这些冻结特征训练下游网络，没有重新训练原始三维 CT 编码器。因此单次训练较快，不能把训练耗时理解为原始影像端到端训练的耗时。详细证据见 [ARCH_AUDIT.md](ARCH_AUDIT.md)。

## 2. 数据隔离与训练设计

方案见 [PROTOCOL.md](PROTOCOL.md)。只用原训练集 521 人进行网络比较，原验证 65 人和原测试 65 人不进入本轮嵌套模型选择。

- 外层三折分别为 174、174、173 人，每名训练患者只贡献一次外层评价。
- 内层训练分别为 277、277、278 人，选训练轮数的内层验证各为 70 人。
- 临床/治疗编码器、归一化、CT 投影和临床基线均只在相应内层训练患者中拟合。
- 新折缓存屏蔽原验证/测试 130 人的标签及可评价标记，外层评估器只处理明确列出的外层患者。
- 六个配置均使用初始化 seed 17、batch 16，预算最多 80 轮 / 1,440 次更新，内层验证 NLL 连续 20 轮未改善则早停。
- `predictive8/32` 前 5 轮仅训练未来状态目标，每折对应 90 次更新。其他配置直接开始结局监督。

外层 OOF 结果用于比较并选择候选，是开发结果，不能再当成候选选择后的独立确认结果。直接 CT 与预测 CT 同时存在条件输入、方差和预热的差异，它们是架构及训练方案对照，不能把全部差异归因于“生成”本身。

## 3. 521 人内部交叉验证结果

下表为记录性复发二分类终点。S0 使用基线 CT 和指定情景信息，S1 可使用真实 CT1 更新；本数据没有新的术后影像观察，当前 S2 与 S1 相同。NLL 为患者归一化后的三个阶段平均负对数似然，越低越好；AUROC 越高越好。

| 模型 | S0 AUROC | S1 AUROC | 三阶段平均 NLL |
| --- | ---: | ---: | ---: |
| 仅临床基线 | 0.5892 | 0.5892 | 0.54661 |
| token_control：原结构对照 | 0.5872 | 0.5789 | 0.56505 |
| token_prior：增加直接 prior CT 监督 | 0.5965 | 0.5989 | 0.54373 |
| direct8：直接 CT，rank 8 | 0.5893 | 0.5932 | 0.54851 |
| direct32：直接 CT，rank 32 | 0.5913 | 0.5961 | 0.54482 |
| predictive8：预测 CT，rank 8 | 0.5889 | 0.5923 | 0.54798 |
| predictive32：预测 CT，rank 32 | 0.5898 | 0.5912 | 0.54670 |

`token_prior` 的 S1 AP 为 0.3182，临床基线为 0.3013。它相对同结构对照的 S1 AUROC 提高约 0.0200，相对临床基线仅提高约 0.0096。其胃癌辅助 pCR AUROC 为 0.5932，临床基线为 0.5929，同样没有明显提升；这些不是远端乳腺任务的结果。

对固定 OOF 预测进行 2,000 次按结局分层的配对 bootstrap，`token_prior` 相对临床基线的 S1 AUROC 差值 95% 区间为 **[-0.0055, 0.0253]**；平均 NLL 差值为 -0.00288，区间 **[-0.00969, 0.00352]**。两个区间都跨过零，且没有包含重新训练及候选选择带来的全部不确定性。因此不能声称已证明稳定提升。

聚合结果见 [summary.json](summary.json) 和 [uncertainty.json](uncertainty.json)。图表为 [ct_results.png](ct_results.png) / [ct_results.pdf](ct_results.pdf)。

## 4. 模型是否实际使用 CT

对 `token_prior` 的外层患者进行固定种子的折内置换，保持模型和临床信息不变：

| S1 输入处理 | AUROC | AP | NLL |
| --- | ---: | ---: | ---: |
| 真实患者 CT | 0.5989 | 0.3182 | 0.54336 |
| 打乱 CT0 与患者对应 | 0.5876 | 0.2982 | 0.55090 |
| CT0/CT1 成对打乱与患者对应 | 0.5904 | 0.2980 | 0.55008 |
| 仅临床基线 | 0.5892 | 0.3013 | 0.54661 |

打乱 CT0 后预测概率平均绝对变化约 0.028，说明网络确实使用了患者 CT0。单独打乱 CT1 时 S1 AUROC 仅从 0.5989 变成 0.5980，说明当前治疗后影像的额外贡献仍然很弱。

这只是固定种子的一次置换诊断，不是因果证据或重复显著性检验；折间方向并不一致，其中一折置换后反而改善。它不能推翻前述“稳定 CT 收益仍未证实”的结论。检查仅涉及原训练 521 人，见 [ct_dependency_probe.json](ct_dependency_probe.json)。

## 5. 未来 CT 预测是否成功

必须检查预测得到的绝对 CT1，不能只检查 `CT1-CT0` 的变化量。变化量含有已知的负 CT0 成分，较好的变化量拟合不一定意味着预测到了未来信息。

| 预测表示 | 预测 CT1 相对训练均值的 R² | 直接复制 CT0 的 R² |
| --- | ---: | ---: |
| rank 8 | -0.233 | -0.523 |
| rank 32 | -0.500 | -0.699 |

两个预测模型都比直接复制 CT0 好，但仍不如各自训练折的 CT1 均值基线。不同 rank 定义不同的目标空间，只能相对于各自基线解释。当前结果不能支持“已经学到了可靠的个体未来 CT 演化”。

## 6. 全量训练后的负结果与模型选择

按预先声明的最低 OOF 三阶段平均 NLL 规则选中 `token_prior`。三个内层选中轮数为 11/10/9，取中位数 10 轮，在原 521 名训练患者上完成 330 次更新。预算配置见 [final_config.json](final_config.json)；包含私有运行信息的原始选择锁定记录不公开。

新增的 `fixed_budget` 策略不在训练过程中使用原验证集选点或早停；完成固定预算后才进行描述性验证评分。自动化测试确认更改验证标签不会改变该模式的训练权重。

原验证集 65 人的导出模型评价：

| 指标 | S0 | S1 |
| --- | ---: | ---: |
| AUROC | 0.5252 | 0.5196 |
| AP | 0.3026 | 0.2987 |
| NLL | 0.55186 | 0.55434 |

导出模型三阶段平均 NLL 为 0.55352，见 [final/evaluation_validation.json](final/evaluation_validation.json)。训练器内部末次评估采用 MC16/seed10017，导出后评估采用 MC32/seed17，NLL 有小幅差异；本报告统一使用导出评估结果。训练记录中的 `validation_evaluations=1` 只统计训练器内部评估，不表示整个流程只对原验证集推理一次。两次评估均在固定预算结束后进行，均未用于本次重训选点。

这个结果低于上一版在相同原验证集上的 AUROC 约 0.6232。内部交叉验证的小幅改善没有稳定迁移到全量训练后的验证结果，本轮不晋升新候选，也未根据这个结果继续调整配置。原验证集规模较小，已有开发使用历史，不能据此精确归因退化原因。

**本轮没有再次评分原测试集。** 上一轮已经查看过的原测试分数不能作为本轮新候选的效果，也不能作为新的独立确认集。旧模型、旧数据和原代码包保留。

## 8. 下一步应验证的方向

优先核查肿瘤候选和 stomach fallback 的定位质量、裁剪范围及两次扫描的一致性，再比较病灶加权、多尺度和现有深层缓存特征。需保留这些质量变量，检验改善是否来自可靠的病灶信息。

未来状态预测可以单独预训练并冻结后，再训练结局读出，分别验证 CT1 预测质量与临床终点收益。两项能力应分别通过训练内对照检验。这些是后续待验证的方向，不是本轮已证实有效的修复；本轮结果尚不支持通过继续堆深当前网络来获得稳定提升。
